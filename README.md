## 🧠 Ringkasan Isi

Tugas ini membahas penerapan **event-driven programming (EDP)** pada aplikasi penjualan sepatu. EDP adalah paradigma pemrograman yang memungkinkan sistem merespons tindakan pengguna secara real-time melalui event seperti klik atau input.

### Komponen Utama EDP:
- **Sumber Peristiwa (Event Source)**: Misalnya tombol kategori atau gambar produk.
- **Event Listener**: Komponen yang mendeteksi event tersebut.
- **Event Handler**: Fungsi yang menangani peristiwa dan menjalankan logika aplikasi.

## 💡 Studi Kasus Aplikasi Sepatu

1. **Halaman Utama (Beranda)**  
   - Event: Klik tombol kategori (Pria, Wanita, Anak)  
   - Aksi: Menampilkan daftar produk sesuai kategori

2. **Pemilihan Produk Sepatu**  
   - Event: Klik gambar atau nama produk  
   - Aksi: Menampilkan detail produk (ukuran, warna, harga, stok)

## ✅ Keuntungan Penggunaan EDP

- Lebih **responsif** terhadap aksi pengguna
- Kode lebih **modular dan mudah dikelola**
- **Efisien** dalam penggunaan sumber daya aplikasi

## 📌 Kesimpulan

Pemrograman berbasis event sangat efektif dalam membangun aplikasi interaktif seperti penjualan sepatu. Dengan pendekatan ini, aplikasi menjadi lebih dinamis, mudah digunakan, dan memberikan pengalaman yang lebih baik bagi pengguna.
